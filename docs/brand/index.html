05 / OPERATING RULES

Three checks keep the system recognisably Hoist.

01

Show the machinery

Name files, paths, versions and consequences. Confidence comes from visible work, not vague automation.

02

Signal with purpose

Orange means action. Mint means healthy. Keep chromatic colour scarce enough that every flash carries meaning.

03

Use plain verbs

Install. Connect. Check. Repair. Hoist sounds capable and direct, never clever at the user’s expense.
